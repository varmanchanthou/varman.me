## 🚀 How to Upload & Publish on GitHub Pages
1. Create a new repository on GitHub (for example, `varmanchanthou.github.io` or `portfolio`).
2. Extract this ZIP file on your computer.
3. Upload `index.html`, `README.md`, and the `assets/` folder to the root of your GitHub repository and click **Commit changes**.
4. In your GitHub repository, go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**, choose **main** (and `/ (root)`), and click **Save**.
6. Your live website will be published within 1–2 minutes!
